# 🐍 Snake Game

A simple, interactive browser-based Snake Game built using HTML, CSS, and JavaScript.

## Features

* Control the snake using Arrow Keys or WASD
* Eat food to increase your score
* Increasing game speed and levels
* Best score saved in browser Local Storage
* Mobile-friendly touch controls
* Game over screen and restart option

## Technologies Used

* HTML
* CSS
* JavaScript
* Canvas API
* Browser Local Storage

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start playing!
